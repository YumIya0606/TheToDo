One port name, and a launcher that actually binds

The engine read PORT while the desktop shell set CLASSRADAR_PORT, and the
generated launcher passed 0 asking the OS for a free port. So the engine came
up on a different port every run and the app could not find it.

- The engine reads CLASSRADAR_PORT, defaulting to 5188, which is the name the
  launcher, the shell and .env.example already agreed on.
- The launcher no longer overrides the port; it only suppresses the duplicate
  banner, since it prints its own.
