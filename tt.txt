## 2. TECH STACK & SYSTEM ARCHITECTURE
- **Desktop Runtime:** Tauri v2 (Rust-backed for ultra-fast startup, near-zero RAM usage, and native OS integration).
- **Frontend Framework:** React 19 + TypeScript (Strict Mode) + Vite.
- **Styling Engine:** Tailwind CSS v4 + Framer Motion (for hardware-accelerated, fluid UI transitions).
- **UI Component Foundation:** Shadcn UI + Lucide Icons.
- **Database / Storage:** - Local SQLite via `tauri-plugin-sql` (for structured task data, tags, meta-analytics).
  - Local File System via `tauri-plugin-fs` (for `.md` / `.json` note storage to ensure complete user ownership and fast backups).
- **State Management:** Zustand with local persistence middleware.
- **Text & Math Engine:** TipTap / Milkdown with KaTeX (`katex`) integration for full LaTeX math/chemistry rendering and `@codemirror` for code blocks.

## 4. DATABASE & DATA SCHEMAS

### A. SQLite Schema (`tasks.db`)
```sql
CREATE TABLE IF NOT EXISTS tasks (
    id TEXT PRIMARY KEY,
    title TEXT NOT NULL,
    description TEXT,
    status TEXT CHECK(status IN ('todo', 'in_progress', 'completed', 'archived')) DEFAULT 'todo',
    priority TEXT CHECK(priority IN ('low', 'medium', 'high', 'urgent')) DEFAULT 'medium',
    category TEXT DEFAULT 'General',
    tags TEXT, -- JSON array of string tags
    completed_subtasks INTEGER DEFAULT 0,
    total_subtasks INTEGER DEFAULT 0,
    linked_note_id TEXT,
    due_date TEXT,
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL
);

CREATE TABLE IF NOT EXISTS subtasks (
    id TEXT PRIMARY KEY,
    task_id TEXT NOT NULL,
    title TEXT NOT NULL,
    is_completed INTEGER DEFAULT 0,
    FOREIGN KEY(task_id) REFERENCES tasks(id) ON DELETE CASCADE
);
B. TypeScript Interfaces (src/types/index.ts)  
TypeScript
export type Priority = 'low' | 'medium' | 'high' | 'urgent';
export type TaskStatus = 'todo' | 'in_progress' | 'completed' | 'archived';

export interface Task {

  status: TaskStatus;

  category: string;
  tags: string[];
  completedSubtasks: number;
  totalSubtasks: number;
  linkedNoteId?: string;
  dueDate?: string;
  createdAt: string;
  updatedAt: string;
  subtasks?: Subtask[];
}

export interface Note {
